# Amazon Review Exporter 图标设计

## 目标

为 Chrome 扩展 Amazon Review Exporter 制作一套简约、在小尺寸下清晰可辨的方形图标，并接入扩展清单。

## 视觉设计

- 使用 Amazon 橙色 `#FF9900` 作为纯色方形底色。
- 橙色铺满整个正方形画布，不依赖透明圆角，保留尽可能大的有效图形区域。
- 中央使用白色“评论气泡 + 小星形”组合图形，表达 Amazon 评论功能。
- 图形使用粗线条或实心几何形，不使用文字、字母、渐变、阴影、纹理或照片效果。
- 构图居中，并留出一致的安全边距，确保缩小至 16px 时仍可识别。
- 不直接复刻 Amazon 商标、微笑箭头或其他受保护的品牌标志。

## 交付物

- 一张高分辨率方形母版图。
- Chrome 扩展使用的 `16×16`、`32×32`、`48×48`、`128×128` PNG 图标。
- 在 `src/manifest.json` 中配置扩展图标和工具栏图标。

## 验收标准

- 所有 PNG 均为对应的精确像素尺寸。
- 各尺寸背景与主体构图一致，无拉伸或额外文字。
- 16px 图标仍能看出白色评论气泡的基本轮廓。
- `manifest.json` 是有效 JSON，且引用的图标路径均存在。
